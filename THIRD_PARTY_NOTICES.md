# Third-party notices

The classic backend and assembled release include identifiers, titles, and excerpts of rule text and control mappings from the publicly released DISA Red Hat Enterprise Linux 8 STIG V2R9 archive. The reviewed archive has SHA-256 `620bdff4d4a5b07b58817297dd5255a3f8f981a7227405c07b098588fe55cdee`. [DISA source archive](https://dl.dod.cyber.mil/wp-content/uploads/stigs/zip/U_RHEL_8_V2R9_STIG.zip) · [DISA public library distribution notice](https://dl.dod.cyber.mil/wp-content/uploads/stigs/pdf/U_STIG_Library-zip_Readme_V2R1.pdf)

This independent project uses Urwid as a separately installed terminal UI dependency. Install Urwid and platform packages from your approved software source. [Urwid project](https://github.com/urwid/urwid) · [Red Hat BaseOS package manifest](https://docs.redhat.com/en/documentation/red_hat_enterprise_linux/8/html/package_manifest/baseos-repository)
